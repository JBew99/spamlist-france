# **App Name**: SpamList France

## Core Features:

- Level Submission: A streamlined form allowing users to propose new Geometry Dash levels with required fields such as unique ID, completion percentage, video proof link, enjoyment rating, and optional comments.
- Dynamic Level Listing: An interactive list displaying submitted levels, featuring detailed information (score, editor, user ratings, links) and functionality for searching and filtering by various criteria like ID or name.
- User Level Rating: A system enabling users to submit a 0-100 enjoyment rating for each level, with automatic calculation and display of the average rating per level.
- AI-Generated Comment Summaries: An AI tool that processes multiple user comments and reviews for a level to generate concise sentiment-based summaries or highlight common themes, enhancing content discoverability.
- Admin Review Panel: A basic, secure tool for designated administrators to review, approve, or reject new level submissions, ensuring quality control and moderating existing level data.
- Community Integration: A dedicated section on the site prominently featuring links to external community platforms, such as Discord, to foster user engagement and discussion.

## Style Guidelines:

- Color scheme is dark with vibrant neon accents, evoking a modern gaming aesthetic. Primary color (calls to action, important highlights): HSL(315, 100%, 65%) / #FF4DDE (a bright, energetic magenta). Background color (for depth and focus): HSL(315, 20%, 15%) / #261F25 (a dark, subtly purple-tinged gray). Accent color (interactive elements, secondary highlights): HSL(285, 90%, 55%) / #950EFB (an electric violet that provides strong contrast).
- Headline and body font: 'Space Grotesk' (sans-serif) for a clean, computerized, and modern feel that aligns with the techy gaming theme and ensures readability for list-based content and short descriptions.
- Icons will be modern, geometric, and crisp, featuring subtle neon glows or outlines that complement the color palette, enhancing interactivity and visual feedback. Use simple, easily recognizable symbols relevant to Geometry Dash actions (e.g., play, share, star for rating).
- A clear, responsive, and data-centric list-based layout, optimized for easy navigation and information density across all device sizes. Inspiration is drawn from popular Geometry Dash list sites, featuring distinct card-like entries for each level with key statistics prominently displayed.
- Subtle, high-performance animations and micro-interactions, such as smooth hover effects, loading indicators, and small celebratory visual feedbacks on actions (like submitting a rating or level), to create an engaging and satisfying user experience without compromising speed.
